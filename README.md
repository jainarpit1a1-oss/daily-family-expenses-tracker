# ServiceNow Family Expenses Tracker

A ServiceNow application for tracking and managing family expenses with automated calculations and reporting.

## Features
- 📝 Add family expense records
- 💰 Automatic total calculations
- 📊 Monthly expense reports
- 👨‍👩‍👧‍👦 Track expenses for multiple family members
- 📧 Email notifications
- 🏷️ Expense categorization (Food, Utilities, Entertainment, etc.)

## Built With
- **ServiceNow Flow Designer** - Automated workflows
- **ServiceNow Form Designer** - User-friendly forms
- **ServiceNow PDI** - Personal Developer Instance

## Installation

See [INSTALLATION.md](INSTALLATION.md) for detailed setup instructions.

**Quick Start:**
1. Download `family_expenses_tracker_v1.0.xml`
2. In ServiceNow: System Update Sets → Import XML file
3. Preview and Commit
4. Search for "Family Expenses Tracker" to use
